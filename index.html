Tata Cara Penggunaan

Sistem ini menyimpan data silsilah di browser Anda (IndexedDB). Data tidak terkirim ke server. Cadangkan file JSON secara berkala agar tidak hilang.

Menu utama

  • Visual Pohon: lihat hubungan keluarga, klik orang atau garis untuk menyorot jalur, geser kanvas untuk menggeser tampilan.
  • Kartu Generasi: anggota dikelompokkan per generasi.
  • Daftar Data: tabel/daftar untuk cari, lihat detail, dan edit anggota.
  • Tambah Anggota: isi nama, generasi (1–100), nomor anak ke, orang tua kandung, ayah/ibu menantu, pasangan, dan foto.

Visual pohon

  • Klik kartu orang untuk mengunci fokus jalur. Klik lagi untuk membuka detail.
  • Garis biru = keturunan ke orang tua, garis kuning putus-putus = pasangan, garis ungu putus-putus = sambungan ke orang tua kandung jika anak sudah menikah ke keluarga lain.
  • Isi Anak ke agar saudara kandung tampil urut (anak ke-1, ke-2, dan seterusnya).
  • Isi Ayah Menantu dan Ibu Menantu agar pasangan tampil di rumah keluarga menantu. Jika kedua pasangan mengisi, kartu berada di tengah kedua keluarga.
  • Zoom dengan tombol + / −, klik persen untuk reset, atau scroll mouse di kanvas.
  • Ikon perluas di pojok kanan atas kanvas untuk preview penuh.
  • Unduh PNG atau PDF dari toolbar visual.

Cara simpan (cadangan)

  1. Buka Opsi DB di header (desktop) atau ikon unduh di ponsel.
  2. Pilih Ekspor (JSON + Foto).
  3. File cadangan JSON akan diunduh. Simpan di folder aman atau cloud.

Penting: data hanya ada di browser ini. Menghapus data situs, ganti perangkat, atau pindah browser membutuhkan file cadangan tersebut.

Cara restore (pulihkan)

  1. Buka Opsi DB lalu pilih Impor Restore (JSON), atau ikon unggah di ponsel.
  2. Pilih file JSON cadangan yang pernah diunduh.
  3. Data lama di browser akan diganti dengan isi file tersebut.

Reset

Menu Reset ke Sample Data menghapus data Anda dan mengembalikan contoh silsilah. Gunakan hanya jika ingin mulai ulang.
